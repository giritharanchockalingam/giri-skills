# Request for Proposal — Integration Platform Modernization (fictional)

## 3. Technical requirements
3.1 The Supplier shall migrate all existing integrations from the incumbent iPaaS to an API gateway platform.
3.2 The Supplier must provide an API developer portal with self-service onboarding for internal teams.
3.3 The solution shall support OAuth 2.0 and mutual TLS for all external APIs.
3.4 The Supplier should provide automated regression testing for every migrated interface.
3.5 The solution must retain all audit logs for a minimum of seven years in-region.

## 4. Delivery requirements
4.1 The Supplier shall complete the migration within twelve months of contract signature.
4.2 The Supplier must provide a named delivery manager with weekly status reporting.
4.3 The Supplier is required to hold ISO 27001 certification in scope for the delivery entity.

## 5. Commercial requirements
5.1 The Supplier shall accept the Authority's standard terms and conditions without exception.
5.2 Pricing should be fixed per migration wave with a not-to-exceed cap.
