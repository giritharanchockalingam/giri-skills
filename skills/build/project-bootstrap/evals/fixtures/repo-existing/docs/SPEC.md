# SPEC — tidewater-booking

<!-- FICTIONAL example SPEC for evals. -->

## Purpose
Let guests of a small marina book a slip online instead of calling the harbour office.

## Users
- Boat owners booking a slip for 1–14 nights.
- Harbour office staff confirming and moving bookings.

## Scope
- In: slip search, booking, cancellation, staff calendar.
- Out: payments (phase 2).
