# Message Templates (skeletons — fill only from supplied facts)

Placeholders in `<angle brackets>`. Facts drawn from the résumé or story bank carry their ID in the draft notes, not in the sent message.

## 1. Referral ask

**A — Direct ask (email, ≤150 words)**
```
Subject: <Role title> at <Company> — referral?

<First name>, I'm applying for <Role title> (<req ID>) at <Company>. Given your time on <their team / with the company>, I'd value a referral if you think it's a fit.

Short version of why: I <one outcome with scale, e.g., led a $XXM platform portfolio and cut Y by Z%> [MR-Lnn], which lines up with the role's <JD responsibility>.

If a referral isn't comfortable, no concern at all — a pointer to the hiring manager would help just as much.

Thanks, <Name>
<Title line>
```

**B — Advice-first (LinkedIn, ≤300 chars)**
```
<First name> — saw <Company> is hiring a <Role title>. Could I get 15 minutes on how the <team> operates before I apply? Happy to work around your calendar. — <Name>
```

## 2. Recruiter reply

**A — Lead with fit**
```
Subject: Re: <Role title> — interested, availability below

<First name>, thanks for reaching out. The role fits: I <one line of scale> [MR-Lnn].

Availability for a screen: <window 1>, <window 2> (<time zone>).
Constraints up front: <location/remote>, travel up to <X>%. Compensation: I'm targeting <range> total; what is the band for this role?

<Name>
```

**B — Qualify first**
```
Subject: Re: <Role title> — two quick questions

<First name>, appreciate the note. Before we book time: what is the compensation band, and is the role <remote / hybrid in city>? If those align, I can speak <window 1> or <window 2>.

<Name>
```

## 3. Post-interview thank-you (≤120 words, one per interviewer)

**A — Reinforce**
```
Subject: Thank you — <Role title> conversation

<First name>, thank you for the time today. Your point about <specific thing they said> stayed with me; it is the same problem I worked through when <one-line story reference> [SB-nn], and I'd approach it here by <one sentence>.

I understand next steps are <what they said>. I look forward to it.

<Name>
```

**B — Repair**
```
Subject: Thank you — and one clarification

<First name>, thank you for today. One answer I'd sharpen: on <topic>, the fuller picture is <two sentences, sourced> [SB-nn]. 

I appreciated your candor on <their priority>; it confirmed my interest.

<Name>
```

## 4. Status check (≤90 words)

**A — Light touch**
```
Subject: <Role title> — quick update from my side

<First name>, when we spoke on <date> you mentioned a decision around <timeline>. I remain very interested. One update: <new information>. Is there a revised timeline I should plan around?

<Name>
```

**B — Competing timeline**
```
Subject: <Role title> — timing

<First name>, I have another process reaching a decision by <date>. <Company> is my preferred option; is it possible to know where things stand by <date − 2>? I'd rather make the decision with full information.

<Name>
```

## 5. Decline (≤100 words)

**A — Clean close**
```
Subject: <Role title> — my decision

<First name>, thank you for the process and for the offer. After careful thought I'm declining, for reasons of <scope / compensation / timing / location>. I was impressed by <specific person or practice> and would welcome staying in touch.

<Name>
```

**B — Door open**
```
Subject: <Role title> — not now, and a thought

<First name>, I'm withdrawing from the <Role title> process because <one-line reason>. If a role with <specific scope> opens in the next <period>, I would want to hear about it.

<Name>
```

## 6. Negotiation open (≤150 words)

**A — Base first**
```
Subject: <Role title> offer — next step

<First name>, thank you for the offer; I want to make this work. One gap: the base of <$X> is below the <$Y> I am seeing for <level> roles with <scope> [market source]. Could we discuss <$Z>? Everything else in the package works. Would a 20-minute call <window 1> or <window 2> suit?

<Name>
```

**B — Package**
```
Subject: <Role title> offer — proposal

<First name>, I'm excited about the role. To bridge the gap to my current package, I'd propose: base <$X>, sign-on <$Y> to cover <forfeited bonus/equity>, and a start date of <date>. Any two of the three would close it. Can we talk <window>?

<Name>
```
