# Competency Map — Executive IT Roles (Sr Director / VP / CIO-track)

| # | Competency | What interviewers probe | JD phrases that signal it | Evidence a STRONG story needs |
|---|---|---|---|---|
| C1 | Technology strategy | Can you set direction, not just execute? | "roadmap", "vision", "strategy", "modernization agenda" | Multi-year plan you authored, funding secured, measurable milestone delivered |
| C2 | P&L / budget ownership | Do you manage money like an owner? | "budget", "P&L", "cost optimization", "run/change" | $ figure owned, variance managed, trade-off decision, savings or reinvestment |
| C3 | Organizational leadership | Can you build and run a large org? | "lead a team of", "build", "develop talent", "succession" | Team size, structure change, promotions/retention numbers, hard people decision |
| C4 | Transformation delivery | Have you changed a platform or operating model at scale? | "transformation", "migration", "legacy", "re-platform" | Scope, duration, before/after KPI, what went wrong and how you recovered |
| C5 | Vendor and contract management | Can you get value from partners? | "vendor", "managed services", "SOW", "contract", "outsourcing" | Contract size, negotiation outcome, SLA governance, exit or consolidation |
| C6 | Stakeholder influence | Can you move executives and peers without authority? | "partner with business", "executive presence", "board", "C-suite" | Named stakeholder level, disagreement resolved, decision changed |
| C7 | Risk, security and compliance | Do you own risk, not delegate it? | "security", "audit", "compliance", "resilience", "SOX/HIPAA/PCI" | Audit outcome, incident handled, control implemented |
| C8 | Operational excellence | Do you run reliable services? | "SLA", "availability", "incident", "ITIL", "SRE" | Reliability metric improved, process installed |
| C9 | Data and AI | Can you turn data/AI into business value responsibly? | "AI", "automation", "analytics", "data platform" | Use case shipped, value measured, governance in place |
| C10 | Change leadership and culture | Do people follow you through change? | "change management", "culture", "agile transformation" | Adoption metric, resistance handled, what you changed in yourself |

## Mapping method
1. Highlight every responsibility and requirement in the JD.
2. Tag each with one competency code. Count tags; the top 4–5 are the interview's center of gravity.
3. Each top competency gets 2 stories (primary + backup). Others get 1.
4. Fit rating: STRONG = all evidence columns present; ADEQUATE = outcome present but scale smaller than the JD; GAP = no source story.

## Level calibration
| Signal | Director answer | Sr Director / VP answer |
|---|---|---|
| Scope in stories | One team, one project | Multiple teams, multi-year, cross-functional |
| Money | Project budget | Portfolio budget, trade-offs across programs |
| Stakeholders | Director/VP peers | C-level, board, external partners |
| Failure stories | Project slip | Strategic bet that did not pay off, and the pivot |
| "What would you do first" | Fix delivery | Listen, baseline, align priorities with the business, then decide |
