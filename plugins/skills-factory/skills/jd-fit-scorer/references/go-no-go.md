# Go / No-Go Thresholds

## Hard-constraint overrides (checked first, before any score)
| Constraint | Source | Effect |
|---|---|---|
| Location outside allowed list and no remote/relocation | user constraints | NO-GO |
| Travel above user max + 15 pts | user constraints | NO-GO |
| Active clearance required that the user does not hold | JD | NO-GO |
| Listed comp band ceiling below user floor | JD + user | NO-GO |
| Any must-have that is a legal/licensing requirement (CPA, bar, PE) with GAP status | JD | NO-GO |

## Score thresholds
| Total score | Must-have coverage | Verdict | Next action |
|---|---|---|---|
| ≥ 80 | ≥ 75% of must-haves MATCH/PARTIAL | GO | Tailor résumé today; find a referral |
| 65–79 | ≥ 60% | LEAN GO | Tailor résumé; address top 2 gaps in cover note |
| 50–64 | ≥ 50% | LEAN NO | Apply only with a referral or if pipeline is thin |
| < 50 or must-have coverage < 50% | — | NO-GO | Pass; log in tracker as "Passed" with reason |

## Tie-breakers for ranking multiple roles
1. Higher must-have coverage.
2. Fewer red flags.
3. Reporting line (CIO/CTO > SVP > VP > Director).
4. Stated comp band.
5. User's industry priority list.

## Required disclosure in output
State the number of PARTIALs that were upgraded or downgraded by judgement and why. The script result and the final result may differ; show both.
