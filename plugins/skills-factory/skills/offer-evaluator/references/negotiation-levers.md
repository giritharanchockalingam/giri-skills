# Negotiation Levers (executive IT roles)

Rank by expected value = (likely gain) × (probability of yes). Ask for the user's judgement on probability; do not assume.

| # | Lever | When it works | Justification to offer | Typical trade |
|---|---|---|---|---|
| L1 | Base salary | Offer below band midpoint; competing offer; user's current base higher | Market band (cite source), scope vs. title, current base | Smallest flexibility at large companies; largest at mid-size |
| L2 | Sign-on bonus | Forfeited bonus/equity at current employer; base is capped | Document the forfeited amount | Easiest yes; one-time |
| L3 | Equity / LTI grant | Public or late-stage private; exec level | Peer grants, retention | Often more flexible than base |
| L4 | Target bonus % | Bonus % below peers at level | Level parity | Rare; usually plan-defined |
| L5 | Title / level | Scope matches a higher level | JD scope, team size, budget | Changes band; ask early |
| L6 | Review timing | Base cannot move now | "Review at 6 months against band midpoint" | Low cost to them |
| L7 | Relocation package | Moving | Actual cost estimate | Easy if a policy exists |
| L8 | Remote / travel terms | Role allows | Productivity, retention | Get in writing |
| L9 | Start date | User needs transition time or a break | Current obligations | Usually flexible |
| L10 | Severance / change-of-control | Exec level, company in flux | Standard exec protection | Ask via counsel if large |
| L11 | Budget / headcount commitments | Role is a turnaround | Mandate clarity | Non-cash, high value |
| L12 | PTO carry-in | Losing accrued PTO | Parity with tenure | Moderate |

## Sequencing
1. Thank, confirm enthusiasm, ask for a call (never negotiate by email only).
2. Lead with the single biggest lever (usually L1 or L3). State the number.
3. Hold L2 (sign-on) as the bridge if L1 stalls.
4. Bundle non-cash items (L6, L8, L9, L11) in the same call; they are cheap for them and valuable for you.
5. Close with a written summary of what was agreed; request the revised letter.

## Rules
- One counter, well justified. A second counter only if they move and a real gap remains.
- Never cite a competing offer that does not exist.
- Ask for the band before anchoring if it was not disclosed.
- Silence after your number; let them respond.
- Decide the walk-away number before the call and write it down.
