# Bullet Formula

```
<Action verb> <what> <scope: team / budget / users / geography> → <metric> <outcome / business consequence>
```
Target ≤ 2 lines (≤ 32 words). Metric where the master résumé has one; otherwise the outcome only. Never add a metric.

| Element | Rule | Executive-level examples |
|---|---|---|
| Action verb | Past tense, leadership scale | Led, Directed, Built, Transformed, Consolidated, Negotiated, Launched, Owned, Restructured, Scaled |
| What | The initiative, platform or org | "the enterprise integration platform", "a 70-person application org" |
| Scope | At least one of: people, dollars, users, sites, regions | "$20M portfolio", "90,000 learners", "12 countries" |
| Metric | Percentage, dollars, time, volume — exactly as in MR | "cut cycle time 70%", "$5M run-rate savings" |
| Outcome | Business consequence, not activity | "enabling same-day disbursement", "retiring 3 legacy systems" |

## Transformation types (for the traceability table)
| Code | Meaning | Allowed? |
|---|---|---|
| REWORD | Same facts, new phrasing or JD keyword | Yes |
| MERGE | Two MR bullets into one | Yes, cite both |
| SPLIT | One MR bullet into two | Yes |
| REORDER | Moved for relevance | Yes |
| TRIM | Detail dropped | Yes |
| EMPHASIZE | Metric or scope moved to front | Yes |
| NEW | Fact not in MR | **No — refuse** |

## Anti-patterns
| Anti-pattern | Fix |
|---|---|
| "Responsible for…" | Start with the verb |
| Activity without outcome ("Managed vendors") | Add the MR outcome or drop |
| Stacked adjectives ("robust, scalable, seamless") | Delete; keep the number |
| Three metrics in one bullet | Split |
| Inflating "participated" to "led" | Keep the MR verb |
| Vague scale ("large team") | Use MR number or omit |

## Verb ladder by level
| Level | Verbs |
|---|---|
| Manager | Delivered, Implemented, Coordinated |
| Director | Led, Built, Launched, Owned, Standardized |
| Sr Director / VP | Directed, Transformed, Consolidated, Restructured, Negotiated, Scaled, Set strategy for |
Use the ladder only where the MR supports that scope.
