# Value-Case Review Rubric

Score 0–3 per criterion. Findings per the redline convention with rewritten content. Total ≥ 20/27 before a steering committee sees it.

| # | Criterion | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|
| 1 | Traceability to stated outcomes | Benefits unrelated to what the client asked for | Loosely related | Mostly traced | Every benefit traces to a client-stated driver |
| 2 | Baselines sourced | Invented | Unsourced | Mostly sourced | All sourced with confidence or marked and excluded from headline |
| 3 | Mechanisms | None | Vague ("efficiency") | Named for most | Every target has a mechanism and enabling milestone |
| 4 | Ranges and ramps | Single point, 100% on day 1 | Point estimates | Ranges, no ramp | Low/base/high with ramps tied to milestones |
| 5 | Costs complete | Delivery only | + licences | + run and transition | + decommission timing, change management, cost of delay (evidenced) |
| 6 | Double counting | Obvious overlaps | Some | Checked informally | Overlap table shown |
| 7 | Finance conventions | Unstated | Stated, unsourced | Client's for some | Client finance's conventions, cited |
| 8 | Sensitivity | None | One variable | Three variables | Three with break-even values; sign-flip risk stated |
| 9 | Realization ownership | None | Some owners | Most | Every benefit owned by a client role with cadence |

## Common findings
| Finding | Rewrite |
|---|---|
| "30% efficiency improvement" | Metric: hours per <transaction> baseline <n> (source); mechanism: automation of <step>; target range; conversion rule |
| Savings start at go-live | Move licence savings to decommission date; add dual-run cost |
| NPV with an assumed discount rate | Undiscounted net; discount rate `[TO BE BASELINED — owner: client finance]` |
| Benchmark-based baseline | Mark L confidence; add client data request with owner; exclude from headline until replaced |
| Benefits summed with strategic items | Separate table; strategic listed |
| No client owner | Flag as unowned risk; add to decision asked |

## Output
1. Scored table.
2. Findings in document order with verdicts and rewrites.
3. Clean revised value case.
4. Unbaselined items with owners.
