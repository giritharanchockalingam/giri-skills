# Storyline Checklist by Deck Type

Check the storyline as found against the pattern for its type. Missing beats are `[ADD]` candidates; extra beats are `[CUT]` or appendix candidates. Order within the pattern may vary if the author's logic holds.

|---|---|---|---|

| Decisions needed today: who, by when, consequence of delay | | | |
