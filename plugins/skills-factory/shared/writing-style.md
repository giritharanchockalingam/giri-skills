# Writing Style (executive voice)

| Element | Rule |
|---|---|
| Voice | Direct, declarative, active. "We recommend X because Y." |
| Sentence length | ≤ 20 words average. One idea per sentence. |
| Headings | Assertions, not labels. "Apigee cuts run-rate 38%" not "Cost Analysis". |
| Numbers | Specific, sourced, rounded for the audience (exec: $5.2M; engineer: $5,214,300). Units always. |
| Jargon | Only what the audience uses daily. Define on first use otherwise. |
| Hedging | None in recommendations. Uncertainty goes in a labeled "Assumptions" or "Risks" row, not in adjectives. |
| Banned words | leverage (verb), synergy, robust, seamless, cutting-edge, genuinely, honestly, straightforward, "it's worth noting" |
| Client-facing | Never include the author's résumé, internal account details, or other-client specifics. Build only from the sources the task provides. |
| Tense | Present for current state, future for plan, past for evidence. Consistent within a section. |
| Lists | Parallel structure. Start each item the same way (verb or noun). |
| Placeholders | `[TO BE BASELINED — owner: ___]` only. No "TBD" without an owner. |
